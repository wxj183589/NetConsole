# NetConsole 本地工具目录

主程序与独立 Agent 采用一致的平台和工具目录命名。Windows x64 工具统一放在：

```text
tools/
└─ windows-x64/
   ├─ fping/
   ├─ iperf3/
   └─ ipop/
```

- `fping/fping.exe` 与 `iperf3/iperf3.exe` 是允许进入正式发布包的内置工具，相关 DLL 与可执行文件保持同目录。
- `ipop/IPOP.EXE` 是用户自行取得的可选第三方工具。仓库忽略该二进制，所有正式发布包均排除它；用户也可在“系统设置 → 外部工具”配置任意本机绝对路径。
- 程序通过统一工具路径解析器定位文件，不依赖当前工作目录，也不回退旧版目录。

仓库没有可核验的 IPOP 再分发许可。对外分发前必须取得并补齐许可证/NOTICE，否则不得把 `IPOP.EXE` 放入任何普通包、工程师包、安装包或 ZIP。
