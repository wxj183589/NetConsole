# IPOP v4.1 本地放置说明

NetConsole 仅提供由用户手动触发的 IPOP 启动入口。需要使用时，请由有权使用该组件的用户将 `IPOP.EXE` 放到本目录。

- 期望版本：v4.1（文件版本 `4.1.0.0`）。
- 期望路径：`tools/IPOP_v4.1/IPOP.EXE`。
- 启动方式：网络工具 → 小工具 → 管理员启动 IPOP v4.1。
- 生命周期：NetConsole 不自动启动、不在后台自动运行，也不在主程序退出时结束 IPOP。
- 授权状态：仓库未提供 IPOP 的 LICENSE/NOTICE，需用户确认再分发授权。

在补齐可核验的 LICENSE/NOTICE 或其他再分发授权前，普通开源包、内部包和客户包均不得内置该二进制。工程师包只允许从构建机本地显式带入；这不代表再分发授权已经获得。
