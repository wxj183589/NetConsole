# Smoke 测试

本目录保存需要明确环境条件的轻量集成/smoke 测试，与普通单元测试分开。测试不得默认访问真实生产设备或写入仓库数据目录。

当前子目录为 `snmp/`；运行前准备脱敏配置或显式环境条件，输出写入临时目录。修改 smoke 契约时同步测试基线与文档说明。

## 用途与边界

本目录只放需要明确环境条件的轻量集成/smoke 测试；不把真实设备、生产数据库或不可控网络依赖伪装成普通单元测试。

## 主要入口

`snmp/` 提供 SNMP smoke 配置样例和测试入口；其他 smoke 域应按相同边界新增子目录。

## 依赖关系

测试依赖 pytest、显式脱敏配置和被测 API/设备适配器；运行参数不能从开发者绝对路径或真实凭据推断。

## 数据与状态

样例配置和输出必须脱敏；测试状态、数据库、日志和报告写入 pytest 临时目录，不写回源码。

## 测试与修改

按环境条件显式运行 smoke 测试，并在修改协议/配置时同步 `tests/README.md`、测试基线和相关 API 测试。

## 生成与清理

测试生成的数据库、日志、抓包和报告使用临时目录；测试结束后由 fixture/pytest 清理，不删除用户已有数据。
