# iPerf3 Windows 动态认证包许可证

本目录随 `iperf-3.21-win64-dynamic-auth.zip` 一起进入 NetConsole 交付包。不同文件受各自上游许可证约束，不能用构建仓库的 Apache-2.0 覆盖整个二进制包：

- `AR51AN_APACHE-2.0.txt`：`ar51an/iperf3-win-builds` 构建与分发仓库许可证；
- `IPERF3_LICENSE.txt`：ESnet iPerf3 3.21 及其内嵌第三方代码的完整许可证/声明；
- `CYGWIN_LGPL-3.0.txt`：Cygwin API Library 的 LGPL-3.0 文本；
- `GPL-3.0.txt`：LGPLv3 所依赖并要求同时提供的 GNU GPLv3 正文；
- `CYGWIN_LINKING_EXCEPTION.txt`：Cygwin Linking Exception 与许可摘要；
- `OPENSSL_APACHE-2.0.txt`：OpenSSL 3.0.19 的 Apache-2.0 文本；
- `ZLIB_LICENSE.txt`：zlib 1.3.2 许可证文本。

精确发行资产、提交、版本和哈希见上级目录 `SOURCE_PROVENANCE.json`；Cygwin 的持续源码交付方案见 `CORRESPONDING_SOURCE.md`。
