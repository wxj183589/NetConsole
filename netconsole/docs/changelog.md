v1.3.0
- 设备管理：设备主数据切换为主用地址、备用地址、系统名称和归属站点，设备管理作为归属站点 SSOT。
- 设备管理：新增设备 MAC 字段，支持从 H3C `display device manuinfo` 的 MAC_ADDRESS 解析并在设备详情中显示。
- 设备管理：设备模板切换为全新精简模板，移除系统名称、SNMP 字段、旧地址字段和隧道本地端口字段；隧道本地端口改为运行时自动分配。
- 设备管理：用户可见字段“站点/位置”统一更名为“归属站点”，并用于 AP 归属站点联动。
- 连接管理：新增统一连接策略，支持主用地址、备用地址和按需 SSH 隧道，优先保障车载 MR 与文件管理远程访问。
- 文件管理：优化 SFTP 连接流程，支持主用、备用、隧道目标重试；SSH 可登录但 SFTP 未开启时，按厂商适配自动尝试启用 SFTP 后重试连接。
- AC管理：FIT-AP资源支持 AP名称 / AP_MAC 搜索，并支持 AP组、状态筛选；移除暂不需要的批量编辑入口。
- AC管理：新增导出 AP 扩展信息模板，模板仅包含 AP名称、AP_MAC、归属站点、里程、点位说明、上下行，并按 AP_MAC 回写。
- AC管理：FIT-AP资源、FIT-AP光衰和轨旁 AP 更新增加加载动画、进度提示和阶段提示，耗时采集、聚合与数据库写入改为异步执行。
- AC管理：修复离线 AP 识别和离线 AP 光告警显示，离线 AP 光告警统一显示为“离线”。
- 轨道交通：轨旁AP业务新增 Link 链路状态列，显示交换机接口 UP / DOWN，端口类型继续保持 access / trunk / hybrid / unknown。
- 轨道交通：轨旁AP业务隐藏并停止导出室内交换机发光字段，保留室内交换机收光字段。
- 轨道交通：优化轨旁AP业务更新流程，增加更新动画和阶段提示，聚合与数据库写入异步执行。
- 轨道交通：修复 XGE / Ten-GigabitEthernet / Ten-GE 接口名归一化，改善 Ten1/0/2 等接口的 LLDP 和光衰匹配。
- 数据持久化：普通采集不再默认写 RAW 日志，采集结果改为运行时缓存和结构化数据库写入，减少 data 目录污染。
- 数据持久化：MESH日志分析写入数据库后自动压缩归档导入源文件，减少 data 目录占用。
- 数据磁盘管理：新增 data 目录磁盘管理，异步扫描并清理临时缓存、调试数据、历史遗留数据，避免误删数据库、报表、配置备份和用户文件。
- UI：左侧导航栏支持收起 / 展开并记忆状态，导航文字居中显示。
- UI：修复 tooltip 和表头说明中的问号乱码，统一归属站点、Link、端口类型等字段说明。
- UI：优化复选框样式，去除复选框后的多余矩形框。

v1.2.0
- AC管理：修复 AP 上线情况概览，停止依赖空 metadata 作为归属主来源，改为以 FIT-AP 光衰记录中的归属站点匹配在线 AP，并补充容量、未归属样本和匹配诊断日志。
- 轨旁AP业务：导出文件新增与 AC 管理一致的 AP 上线情况概览工作表，并修复 AP 侧无光模块、无光衰数据时的显示、染色和统计口径。
- 无线扫描：新增混合扫描模式，合并 Windows WLAN API 与 netsh 结果，同一 BSSID 只显示一条记录，并同时显示频宽、MIMO、加密方式和认证方式。
- 轨道交通：优化轨旁AP业务加载逻辑，修复进入页面空表、首次点击卡顿、进度文字异常、接口历史窗口嵌入主页和光模块历史被遮挡问题。
- 轨旁AP业务：新增光衰采集更新，复用 FIT-AP 光衰诊断逻辑，隐藏内部连接字段和未本地化状态字段，并同步修复导出字段。
- MESH日志分析：新增分析报告导出，支持主链路切换顺序、来回切换、建链顺序、Peer 生命周期、无 Active、多 Active、RSSI、信道繁忙度、原始事件和解析问题统计。
- MESH日志分析：优化 Peer 趋势窗口，支持 Hover 提示、滚轮缩放、拖拽平移、时间滚动条、锚点居中和长时间数据降采样。
- 车载MR在线收集：新增 Fast Pinger v3 工具发现与版本检测，支持高频 Ping 命令构造、输出解析、汇总解析、Ping 采样持久化和 Active 主链路段聚合。
- 车载MR在线收集：新增 MESH 主链路、信道繁忙度、AP 射频统计、切换历史最新记录和接口速率 repeat 采集命令，并支持 Ctrl+C 停止 repeat。
- 车载MR在线收集：重组页面布局，拆分连接、采集周期、射频参数、高频 Ping、高级参数、实时状态和详情页签，限制输入框宽度并保存表格列宽。
- 在线诊断存储：将在线采集会话统一保存到 rail_transit/online_mr 目录，使用 online_diagnosis.sqlite 保存 Ping、接口速率、终端事件和最新切换历史。
- 网络工具：新增 IPERF 带宽测试与无线扫描功能，无线扫描支持轨旁 AP BSSID 反查、频宽/MIMO 解析、主表导出和扫描源选择保存。
- 启动体验：新增启动预加载和加载动画，删除启动页 Net Tools 副标题，统一 Splash、更新日志、主窗口和关于窗口的版本显示。
- 打包：修复 tools 目录未进入发布包的问题，将 tools/fping_v3/Fping_v3.exe 和 tools/iperf/iperf3.exe 统一放入 _internal/tools，并更新清理打包白名单。
- 稳定性：完善后台 Worker、取消任务、异常恢复、缓存、列宽保存、多语言显示和全量回归测试覆盖。
