# 设备文件下载页面

本目录展示受控 SFTP 设备文件浏览和本地下载；同一模块下还包含配置采集中心与设备诊断下载页。设备端只读，不提供上传、删除、重命名、移动或远程建目录；路径安全、传输队列和数据目录由 Python File Service/Job 管理，页面只传递受控输入。

选择设备会断开旧会话、清空远程状态并加载该设备专属真实下载目录。“MESH 日志”只更新当前目录的勾选状态，统一由“下载选中”创建单并发队列。任务完成即已落盘，页面刷新左侧列表；打开文件和所在目录使用 Electron Desktop Bridge 的一次性 opaque 动作，不提供二次“保存”。

目录和文件目标由 Backend 消费一次性动作后完成受控路径校验，真正的系统打开由 Electron Main 使用 `shell.openPath` 执行。页面请求期间禁止重复触发；Windows 未把资源管理器切到前台时，由 Electron 最小化仍保持焦点的 NetConsole 窗口作为可见性兜底。

主要入口为 `FileManagementView.vue`、模型和 i18n 文件。修改下载状态或路径展示时运行本目录测试，确认没有把运行数据写入源码目录。

首屏能力状态完成后即移除页面级 loading；本地目录、设备列表、下载队列和远程目录分别使用
`localLoading`、`deviceLoading`、`queueLoading`、`remoteLoading`。首次队列只取 20 条且不阻塞设备选择。

SFTP 连接成功后显示 Backend 返回的原始目标角色、地址和跳板入口，不展示本地随机转发端口。
失败时按候选路径展示脱敏摘要；Renderer 不自行推断主备或隧道选择。
连接期间状态栏提示单条路径最多等待 5 秒，并说明失败后会自动尝试下一路径。
