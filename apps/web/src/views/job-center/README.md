# Job Center 页面

本目录展示后台 Job 列表、详情、事件日志和取消状态。任务执行仍由 Python Job Center/Worker 负责，页面不得阻塞等待长任务或直接启动进程。

主要入口为 `JobCenterView.vue`；数据通过 Task API 获取。修改状态、游标或取消交互时运行页面测试并检查 Job 契约。

任务列表使用 `NcDataTable`，任务/状态/进度仍由现有插槽展示，错误摘要明确为长文本左对齐。公共表格只持久化列布局，不建立第二套任务模型，也不改变取消、日志和 Artifact 授权。

任务指标、日志级别和代码表面消费全局状态/代码 Token；页面不维护独立浅色卡片或日志配色。
