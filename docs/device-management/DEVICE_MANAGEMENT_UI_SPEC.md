# 设备管理 UI 规范

设备管理工作区保持左侧分组、中间设备列表和右侧详情抽屉的布局。分组、列表、筛选和详情各自滚动。窄窗口使用抽屉，桌面宽屏保持列表与详情的可读宽度。

左侧只显示通用设备分组，包括全部设备、未分组和用户分组。线路、车站、区间和车辆段不进入设备分组。

中间列表使用服务端分页和 `NcDataTable`。名称、厂商、型号、管理 IP、连接状态、采集状态和只读工程归属可见。在线状态、采集状态、凭据状态和工程关联状态保持独立语义。

详情继续复用 `DeviceDetailPanel`。概览中新增“轨道交通工程归属”区域，显示线路、工程节点、节点编号、节点类型、工程角色、建设项目和 AC 服务站点。关联数据不可用时显示状态提示，未关联时显示未关联状态。入口只跳转到基础设施页面，不在设备详情维护工程关系。

设备创建和编辑只处理设备资产字段。工程字段由基础设施或对应业务配置维护。批量操作继续复用现有 Task Center、连接测试、采集和导出流程。
