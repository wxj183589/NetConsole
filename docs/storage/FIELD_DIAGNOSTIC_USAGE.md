# 现场诊断包使用

1. 打开 NetConsole。
2. 进入“应用日志与安全维护”。
3. 选择采样时长（默认 5 分钟）和日志范围。Raw 样本默认关闭；仅在确有排障需要并确认可以带出当前局点报文时勾选。
4. 点击“导出现场诊断包”，在 Save As 中选择位置。
5. 等待任务完成，将生成的 ZIP 带回分析。

采集过程只读，不会停止 Ground、UDP、Raw Writer、Parser 或 Online MR。文件与 Raw 范围被限制在当前局点，磁盘性能范围被限制在数据根所在卷。RAID/CIM 不可用时仍会生成 ZIP，并在 `manifest.json` 中记录原因。
