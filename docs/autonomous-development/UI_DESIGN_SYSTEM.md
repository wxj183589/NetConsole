# NetConsole UI 设计与交互规范

## 范围

适用于 Electron 中的业务工作区与共享 Vue 组件。页面保留既有局点、设备、任务和权限关系。改动涉及业务规则时单独验收。

## 设计变量

- 背景用 `--nc-bg-app` 和 `--nc-bg-panel`，主要文本及边框从共享主题读取。
- 语义色由共享状态组件和主题变量控制。亮色和深色主题保持状态对比度，状态同时提供文字。
- 表格优先使用 `NcDataTable`，状态呈现复用语义状态组件，危险操作复用确认对话框。

## 页面行为

- 页面顶部放标题和当前上下文。高频操作固定在工具栏，低频参数与原始数据放详情。
- 默认表格先展示状态、主要对象、关系和问题。筛选与排序仍按实际字段工作。
- 任务执行状态与业务结果各自显示。常见文案包括执行中、部分成功、失败、已取消、有告警、已中断和已停止。
- 键盘可进入行操作和详情。展开控件需要明确名称，窄窗可滚动或折行。

## 异常

- 默认反馈显示受影响的对象和操作。原始 API 或 Worker 错误放可展开详情，便于定位。
- 空结果、未知、读取失败、已取消和部分成功分别呈现。刷新或重试后应显示当前请求结果。
- 确认对话框标明目标和影响。切换局点或目标时清理旧请求与未确认操作上下文。

## 验收

- 核对常用路径的默认视图、展开详情、加载、空态和失败态。
- 核对中文状态与原始状态对应，尤其是取消、告警和部分成功。
- 验证键盘操作、窄窗口滚动和亮暗主题。共享组件改动覆盖直接消费者，真实桌面验收记录源码版本和环境。
