## 性能观察

同一采集脚本记录路由导航到两帧后与随后约 425 ms 内的 API 请求。Phase 1 开着源码热更新，部分基线样本被刷新干扰，且两次机器负载未严格控制。可用的 1920×1080 单次样本中，FIT-AP 329→333 ms（4→4 次请求），地面回放 69→62 ms（2→2 次），设备管理 98→341 ms（4→4 次），首页 44→41 ms（5→10 次）。设备管理耗时及首页请求数变化需要稳定环境重复采样。大表格滚动、长时请求及实际工作量性能仍待验。[基线](../../../reports/tests/legacy-ui-ux-phase2/baseline.json) · [候选](../../../reports/tests/legacy-ui-ux-phase2/candidate.json)
