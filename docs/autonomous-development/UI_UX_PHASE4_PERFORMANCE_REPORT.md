混合压力采样在独立演示根执行 1,802 秒，共 390 次采样。循环切换 Ground 实时与回放、日志、任务、设备管理和 FIT-AP，并查询日志。1,632 个 API 请求，未记录 HTTP 或 Renderer 异常。SQL 响应计时累计 11.10 秒，Renderer JS Heap 为 24.6–70.5 MB，末次 46.1 MB，Renderer TaskDuration 累计 88.23 秒。压测期间源码工作树有改动，采集关闭。真实高频采集、连续绘图、已派发任务队列积压和进程总体 CPU、内存尚未测量。
