# 开发约定

本文档记录 NetConsole 长期开发约定。新增功能、修复问题、整理数据、改导出或调整打包前应先阅读。

## 基本原则

- 只改当前需求直接相关范围。
- 不重构无关模块。
- 不删除仍在使用的入口。
- 不因为 UI 优化破坏采集、解析、导入导出、后台任务或打包。
- 优先复用现有组件、状态管理、服务、repository、数据库结构和路径服务。
- 如需调整数据结构，按当前正式方式处理，并说明是否需要初始化或重建。

## 禁止硬编码

正式代码和文档规则中禁止写死：

- 局点名称、线路名称、站点名。
- 设备名、AP 名、AC 名、MR 名。
- MAC、IP、端口、车号、固定列车清单。
- 用户本机路径。
- 截图里的样例数据。
- 某个特定项目、特定车号、特定 AP 的特殊处理。

允许使用示例时必须写明“示例”或“调试环境”，不能作为业务规则。

## 禁止临时兼容补丁

正式代码中禁止：

- 为旧字段缺失写猜测逻辑。
- 为某次导入数据写特殊分支。
- 用 `try/except` 吃掉结构性错误。
- 用 `setTimeout`、无界轮询或延迟调用掩盖递归、阻塞或状态错乱。
- 只针对截图现象做假修复。
- 为了兼容历史不一致结果保留旧 `remark` 或旧规则，除非需求明确要求。

如果旧数据和当前规则冲突，默认以当前统一规则为准；需要保留历史输出时必须在需求和说明中明确。

## 中文化

- 新增 UI 文案、提示、空状态、错误提示、tooltip 默认中文。
- 不直接暴露内部字段名。
- 文档以中文为主，必要英文技术术语可保留。
- 面向用户的提交说明、打包说明和变更摘要默认中文。

## 性能约定

- 后续新增页面、弹窗、导出、后台任务、表格和文本读取必须遵守 [存量例外与新增代码约束](ui_governance_guardrails.md)。
- 全局强制遵守 [UI 线程全局规范](ui_thread_policy.md)：UI 线程只负责 UI。
- 耗时任务、网络任务、数据库大查询、文件扫描、解析、压缩、图表生成、设备连接必须使用后台线程或独立进程。
- 后台任务必须遵守[后台任务规范](background_task_policy.md)，Worker 不得访问 DOM、Renderer 或 Electron 对象，进度、结果和错误通过正式任务事件返回。
- 所有导出类任务必须遵守 [导出进程规范](export_process_policy.md)，使用独立进程，不得在按钮回调或 UI 线程直接写 Excel/CSV/PDF/图表。
- 大表格不要一次性渲染无分页、无窗口的全量数据。
- 大图表需要抽样、数据窗口、懒加载、progressive 或等效策略。
- AC 管理和轨道交通模块切换必须懒加载，不一次性初始化所有子页。
- 模块切换不能中断后台采集、检测或导出任务。
- 采集、解析、大文件处理不得阻塞 UI 主线程。
- 主题切换不能在 `changeEvent` 中递归触发 `setStyleSheet`。
- 主题切换只更新视觉状态，不重建页面、不清空日志、不停止任务、不重新查询设备。

## 功能开关

新增用户可见模块、页面、标签页、动作、按钮或入口，默认接入集中式功能开关：

- 在 `src/netconsole/core/feature_registry.py` 注册 feature ID。
- 使用 `FeatureGate` 控制 UI 创建、入口显示或动作处理。
- 通过既有 profile / 功能配置流程暴露配置。
- 避免散落一次性 `if`。

纯内部修复、测试辅助、非用户可见重构可以不新增 feature ID。

## 本地 `.xlsx` 与 WPS 边界

默认不新增 WPS 云服务、WPS API、KDocs 或在线同步能力。  
本地 `.xlsx` 导出格式优化仍在范围内，包括：

- 表头冻结。
- 自动筛选。
- 列宽和行高。
- 文本格式。
- 多工作表结构。
- 便于 WPS Office / Microsoft Office 打开的本地文件体验。

## 主题和 UI 样式

- 页面应接入全局主题机制。
- 不在 `changeEvent` 中调用会 `setStyleSheet` 的 `apply_theme()`。
- 已打开页面的主题刷新应由主窗口或统一主题入口显式触发。
- 对重复点击当前主题应跳过无效全量刷新。
- 自绘或组合式拓扑控件只保存主题 token 并 `update()`，不要通过事件递归设置样式。

## UI 表格规范

新增或修改表格时，必须遵守 [UI 表格与全选框规范](ui_table_guidelines.md)。

要求：

- 勾选列使用 `el-table-column type="selection"` 和稳定业务 ID。
- 全选、反选和清空选择必须同步更新页面状态与批量动作可用性。
- 表格使用明确宽度或 `min-width`，并允许用户手动拖动。
- 不允许为塞进窗口而强行压缩核心字段。
- 超宽表格必须使用横向滚动条。

## Windows 网络调试安全

本地网卡配置和路由管理是高风险功能。调试时：

- 不得修改当前正在使用的活动网卡。
- 优先使用独立 USB 调试网卡。
- 调试安全约束不能写成生产功能硬编码。

## 验证约定

- 文档改动：检查链接、文件名和“当前实现/约定/待统一”边界。
- 导入导出：检查表头、列宽、筛选、冻结、样式和空状态。
- 采集解析：覆盖成功、失败、空数据、离线、异常状态。
- UI 入口：检查显示、隐藏、启用、禁用和状态保留。
- 打包：检查发布包白名单、禁入目录、工具文件和启动自检。
- 涉及耗时任务：说明 Renderer 是否只负责 UI、任务使用 Job Center 还是 Export Process、是否有进度/取消/失败提示/日志和退出清理。
- 涉及导出：说明是否走独立进程、是否通过 job 参数传递数据、是否避免 UI 线程直接 `Workbook.save()` / `df.to_excel()` / `matplotlib.savefig()`。
