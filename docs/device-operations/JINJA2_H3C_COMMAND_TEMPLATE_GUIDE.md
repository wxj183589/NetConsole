# H3C Jinja2 命令模板

在任务中心选择「创建设备任务」和「自定义命令采集」，填写模板、参数定义和参数值，再预览命令。提交时，后端重新渲染并校验最终命令，设备只执行白名单中的查询。

## 只读采集

```jinja2
{# 查询交换机指定接口的光模块诊断信息 #}
display transceiver diagnosis interface {{ interface }}
```

参数定义

```json
{
  "interface": {
    "type": "interface",
    "required": true,
    "description": "设备接口名称"
  }
}
```

参数值

```json
{"interface": "GigabitEthernet1/0/1"}
```

支持的参数类型为 `string`、`interface`、`integer`、`boolean`、`list` 和 `object`。可选参数可以设置默认值。模板支持注释、变量、循环、条件，以及 `default`、`join`、`lower`、`upper` 和 `trim`。渲染使用 Jinja2 Sandbox 和 `StrictUndefined`。参数中的换行和控制字符会导致校验失败。

## 配置命令预览

```jinja2
{#
预览 VLAN 命令。
变量 vlans 使用 list 类型。
#}
{% for vlan in vlans %}
vlan {{ vlan.id }}
{% if vlan.name %}
 name {{ vlan.name | lower }}
{% endif %}
 quit
{% endfor %}
save force
```

模板可以预览配置变更命令。此类结果标记为 `configuration_change`，只有通过逐条白名单校验的结果可作为只读采集任务提交。最多提交八条查询命令。

## 执行与结果

设备任务使用现有 Job Center。每次手动执行的 Task ID 同时用作 Run ID，失败重试生成新的 Run ID 并记录原任务 ID。设备目标可选择当前局点设备 UUID、设备分组、局点全部设备或已初始化的组织节点及其下级。目标在提交时冻结，每次最多 64 台。并发可设为 1 至 8，设为 1 时串行执行，同一台设备按顺序执行命令。

LLDP、诊断、版本、无线信息、MESH 与自定义查询支持 5 至 120 秒的单条命令超时。配置备份和光衰沿用各自采集器的超时策略。停止请求会阻止后续设备连接和后续命令，正在执行的采集器按其取消检查或进程停止机制收口。任务结束后才能重试失败设备或导出结果。

逐设备结果包含开始、完成时间、联网采集耗时和脱敏结果。XLSX 导出先选择保存位置，再通过独立 Export Worker 生成受管 Artifact，由统一保存协调器落盘。超过 Excel 单元格限制的完整结果 JSON 分段写入，按设备和分段顺序可重组。

配置收集和备份复用配置中心的 running/saved 快照。光衰任务复用设备光模块采集，按本次采集 ID 获取结果。LLDP、诊断、版本和自定义命令的回显进入逐设备结果。命令结果会脱敏并限制长度。任务状态、进度和事件保存在现有任务数据库，可从「应用日志与安全维护」的「任务日志」通过同一 ID 查询。

无线信息与 MESH 收集支持 H3C AC。无线信息查询 AP 列表、地址和射频信息，MESH 查询设备时间和 Mesh-Link，复用已有解析器。结果保留在本次任务中，AC/MESH Current 与身份关联仍经原采集入口维护。其他设备角色或明确不支持的命令返回跳过。无法解析的非空回显返回失败，明确的零 AP、零链路可成功。每台设备保留前 128 条解析记录并显示截断状态。

## 局点模板库

填写模板名称、分类、适用设备及命令类型后，可以保存并在当前局点重复使用。修改模板或启停都会生成新版本。通过版本历史载入先前内容并保存，可以恢复为最新版本。复制模板会创建新的模板记录。

新建、更新与复制只接受只读模板。保存时检查每个条件分支和循环体，命令名称需固定，变量用于接口等查询参数。例如可以保存 `display transceiver diagnosis interface {{ interface }}`。动态拼接整个命令或查询名称会被拒绝，历史配置变更模板继续保留读取与预览。

运行已保存模板时，预览校验模板版本和输入参数。提交时重新计算校验值，通过后才生成任务。版本变更、停用和参数修改需要重新预览。已保存模板的失败设备可在任务中心使用当前版本重新发起。

当前交付覆盖手动只读采集、模板库和配置变更命令预览。模板文件导入导出、计划任务、持续监控、可确认的配置下发、升级计划和日志推送仍待交付。LLDP 任务结果尚未成为组织自动归组的 Current 数据源。
