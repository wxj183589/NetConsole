# 设备任务发布前审计

| 场景 | 行为与验证 |
| --- | --- |
| 新旧数据 | 设备列表按已有 owner、任务类型和 Site 范围读取。计划文件缺失时返回空列表，首次创建写入版本 1。此功能无需转换既有任务或模板记录。 |
| 历史执行快照 | 集中采集记录设备 UUID、执行时设备名称、结果、命令及模板版本。历史重试使用旧执行快照，重新核对当前局点设备和命令白名单。没有各设备结果的旧记录无法重试。 |
| Site 切换 | 列表及统计请求带预期 Site，前端切换时清空并丢弃旧响应。共享详情抽屉使用独立请求代际，关闭抽屉作废在途请求。现有详情、日志和取消接口请求时读取当前 Site，未携带列表的预期 Site。对相同任务 ID 跨 Site 的短窗口仍需集成验证。 |
| 计划恢复 | 计划与任务使用固定 ID。任务已写入而计划尚未回写时，恢复扫描复用现有执行记录，测试模拟该窗口并验证未二次提交。 |
| 进程崩溃 | 任务记录写入后、Worker 开始前崩溃时，Job Center 按遗留任务流程核对执行记录。计划恢复会识别该任务 ID，用户可查看执行终态。无法以此保证设备命令恰好执行一次。 |
| Terminal SFTP | 实际传输阶段以 Site 和设备 UUID 请求同一个资源锁。空闲会话和下载完成后等待另存保持可用。回归覆盖设备 Worker 阻塞下载，以及终端任务进入 READY 后释放锁。 |

上述设备执行、文件传输与故障均使用隔离测试。真实设备、真实路径与安装包验证待执行。
