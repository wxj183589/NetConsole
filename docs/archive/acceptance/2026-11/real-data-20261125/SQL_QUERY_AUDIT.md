## 跨 Run 有界分页及全局时间索引复测

2026-11-27 在只读 HZL10 来源之外创建单文件数据库候选，候选创建时 SHA-256 与来源相同。来源文件 SHA-256 为 `F19ACEA0D377D7BC1C090BB1A61532D274F4E6364EBB7467FCE9064B9F01E87E`，大小 `6,322,176,000` bytes。测试只修改候选库。

新增十个按 Site、`julianday(timestamp)` 和来源稳定身份排序的覆盖索引。来源范围 SQL 现在先使用对应索引排序并读取每个来源最多 `page_size + 1` 行，再在内存中按原全局顺序合并。跨来源游标谓词在限量前应用。缺少新索引的旧数据库继续走兼容查询路径；未带游标的旧 OFFSET 页仍保留既有路径。
