# Console 设置与会话回放验收

## 设置

旧版启动把基础设置和 22 条关键字规则放在同一个 Promise 批次中，规则请求延迟或失败会拖住基础设置发布。日志页没有延迟挂载，危险规则页首次进入会同时创建 226 行可编辑控件。服务每次读取规则都会重新打开文件、解码、解析和验证。

现将设置和规则独立发布。弹窗先绘制外壳，再加载设置草稿。规则页按需加载，每页最多 25 行，离开规则页卸载表格，关闭弹窗取消读取并清理草稿。后端按文件元数据缓存已解析内容，写入后使缓存失效，继续使用现有原子替换。日志页使用同一基础设置，无独立读取。

| 场景 | 实测或状态 |
| --- | --- |
| 旧版 `fbcf31e8`，已有缓存和模拟 SSH | 热开 30 次中位数 28 ms，24–32 ms；无同口径冷缓存对照 |
| 续作四，真实 Electron，Console 已加载，双模拟 SSH 分屏 | 最终首开外壳 75 ms、可交互 83 ms；其中一轮分别为 107 ms、120 ms |
| 续作四，30 次热开 | 最终中位数 55 ms、P95 62 ms、范围 46–63 ms |
| 22 条高亮、226 条危险规则、日志 | 最终分别为 1,057/224/43 ms，包含控件就绪和 Playwright 等待 |
| 设置读取、保存失败与重试 | Electron 定向注入通过，失败后保留草稿，重试保存成功 |
| 真正冷磁盘、真实 Telnet/COM、持续混合高输出、CPU/内存、独立 IPC/文件/解析计时 | 未完成测量 |

Electron 指标是交互计时。早期的 28 ms 只有热缓存外壳计时。续作四热开外壳比该历史样本慢，危险规则页的 DOM 上限由 226 行降至 25 行；尚无相同环境下可量化的危险规则前后耗时对照。

## 会话记录搜索

在「会话记录与导出」输入关键字，使用上下按钮或 Enter / Shift+Enter 循环定位。Ctrl+F 聚焦搜索，Esc 清除搜索，空搜索时再次 Esc 关闭窗口。按字面搜索，英文忽略大小写，并支持中文、IP、MAC 和标点。当前项使用独立颜色。搜索先防抖，再按时间预算分段建立浏览器文本范围。切换记录和关闭窗口时释放请求、扫描及高亮注册。

回放从原始事件读取有界彩色预览，保留可读转录与基础及亮色 ANSI 前景、背景色。扩展 256 色及真彩 SGR 当前不映射。长录制在预览上限内搜索，超出部分可从原始导出查看。导出继续读取原文件，搜索不向记录或导出写入内容。

真实 Electron 验证 720,075 字符、跨 ANSI 颜色的英文关键字、中文、IP、MAC、Comware 命令、特殊字符、空搜索、零结果和循环按键。2560×1440 和 1920×1080 Renderer 截图保存于 Workspace `reports/tests/console-1.5.19-resume-20261126/console-replay-20261127/`。独立真实 SSH/SFTP 复合验收测得 Electron 窗口两种尺寸，2560×1440 匹配物理显示器。

真实隔离 SSH 录制经搜索前后重复请求正式导出路径，三种 SHA-256 一致，详见同一证据目录下 `ssh-export/evidence.json`。测试根与业务数据隔离。

## 门禁

Python 定向 56 项、Renderer 定向 50 项、Electron 328 项通过。Renderer 和 Electron 类型检查与构建通过，设置及转录服务 Ruff 通过。已验证生产 Renderer CSS 包含 `::highlight` 规则。构建依赖锁定闭包通过。旧未跟踪缓存使 Workspace Layout 失败，Full Gate、Full NSIS 和 Portable ZIP 当前无新制品或 SHA-256。
