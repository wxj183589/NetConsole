# Console 设置与会话回放验收

## 设置

旧版启动把基础设置和 22 条关键字规则放在同一个 Promise 批次中，规则请求延迟或失败会拖住基础设置发布。日志页没有延迟挂载，危险规则页首次进入会同时创建 226 行可编辑控件。服务每次读取规则都会重新打开文件、解码、解析和验证。

现将设置和规则独立发布。弹窗先绘制外壳，再加载设置草稿。规则页按需加载，每页最多 25 行，离开规则页卸载表格。规则编辑器使用轻量原生控件。后端按文件 mtime/ctime/size 缓存解析内容，外部修改和原子保存都会使缓存失效。

| 场景 | 实测或状态 |
| --- | --- |
| 旧版 `fbcf31e8`，已有缓存和模拟 SSH | 热开 30 次中位数 28 ms，24–32 ms；无同口径冷缓存对照 |
| 续作四，真实 Electron，Console 已加载，双模拟 SSH 分屏 | 最终首开外壳 75 ms、可交互 83 ms；其中一轮分别为 107 ms、120 ms |
| 续作四，30 次热开 | 最终中位数 55 ms、P95 62 ms、范围 46–63 ms |
| 22 条高亮、226 条危险规则、日志 | 最终分别为 1,057/224/43 ms，包含控件就绪和 Playwright 等待 |
| 设置读取、保存失败与重试 | Electron 定向注入通过，失败后保留草稿，重试保存成功 |
| 首次规则页查询，热缓存和双模拟 SSH | 关键字 1,057 ms、高危规则 224 ms，含控件等待 |
| 逐页轻量化后，同步 Full Gate 负载下 | 关键字页签 364 ms、高危规则 91 ms；其中包括异步读取、页面创建和交互等待 |
| 真正冷磁盘、实体 Telnet/COM、持续高输出及进程资源 | 未完成测量 |

Electron 指标来自 Console 已加载、双模拟 SSH 分屏的真实 Electron 运行。空闲负载热开 30 次外壳中位数 57 ms、P95 约 62 ms、Renderer long-task 总量 0 ms。与 Full Gate 的 CPU 密集 Python 套件并发时，首开外壳 281 ms、可交互 293 ms。此前 28 ms 是不同脚本口径的单项外壳时间。规则每页只挂载 25 行轻量原生输入；真实冷磁盘读和同条件前后基准仍缺失。

## 会话记录搜索

在「会话记录与导出」输入关键字，使用上下按钮或 Enter / Shift+Enter 循环定位。Ctrl+F 聚焦搜索，Esc 清除搜索，空搜索时再次 Esc 关闭窗口。按字面搜索，英文忽略大小写，并支持中文、IP、MAC 和标点。当前项使用独立颜色。搜索先防抖，再按时间预算分段建立浏览器文本范围。切换记录和关闭窗口时释放请求、扫描及高亮注册。

预览被截断时，搜索 API 在线程中逐条读取完整 JSONL，用共用转录状态机抽取文本并跨 SGR 和 event 边界匹配。扫描支持断开取消，定位接口只返回命中上下文。支持基础/亮色、256 色、24-bit RGB 前景/背景及常见 SGR 属性，不把原始控制序列放入 HTML。

真实 Electron 验证超过 1 MiB 的隔离 SSH 录制、跨 256 色/True Color 分段的匹配、中文、IP、MAC、特殊字符、取消和循环定位。截图见 Workspace `reports/tests/console-1.5.19-resume-20261126/console-final-20261127/full-recording/`。
