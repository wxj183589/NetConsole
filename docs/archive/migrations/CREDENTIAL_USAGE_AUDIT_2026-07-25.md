因此，`legacy-localappdata-agent` 应记录为迁移遗留目录，不应在未取得授权前删除或自动迁移；不存在 `agents\\local` 目前属于“没有活动 Agent 实例的正常状态”，不能据此推断历史凭据已经失效。

### Web 认证入口

Go Agent API 的实际认证入口是可选的 `X-Agent-Token` 请求头。`web_username/web_password` 只作为配置结构字段被读取并在配置响应中脱敏，当前代码没有用户名/密码登录流程。Agent Web 页面也只提供 Token 输入，不使用 Web 密码。Electron Python Backend 使用进程内临时会话令牌，该令牌不等同于历史 Agent Token，也不读取 Agent Web 密码。

据此，历史 Web 密码对应的用户名/密码登录功能已被当前实现替代，不能生成替代密码；若现场仍有独立旧部署，需由管理员单独确认。
