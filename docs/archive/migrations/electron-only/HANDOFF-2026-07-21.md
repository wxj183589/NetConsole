## 3. 本轮最后一个完成任务：MESH 空口负载图表

最后完成并推送的任务是：

```text
轨道交通 / MR 原始 MESH 日志分析 / 空口负载
增加“显示切换时刻线”和“显示切换节点”。
```

已实现事实：

1. 空口负载图新增两个独立开关：
   - `显示切换时刻线`
   - `显示切换节点`
2. 默认均为关闭，避免大数据场景下满屏黄色线或红色节点导致不可读。
3. 切换时刻线按 `ACTIVE_SWITCH` 事件时间绘制黄色虚线。
4. 切换节点不使用事件对象的坐标兜底值，而是使用后端返回的 Busy 对齐点：
   - 优先 `local_tx_busy`
   - 缺失时使用 `local_rx_busy`
   - 无 Busy 对齐点则不画节点
5. 后端 `MeshChartEventDTO` 新增 Busy 对齐元数据：
   - `render_busy_point_timestamp`
   - `render_busy_point_index`
   - `render_busy_tx_busy`
   - `render_busy_rx_busy`
   - `render_busy_aligned`
   - `busy_point_context`
6. 降采样预算继续使用 `MeshAnalysisQueryService._chart_render_budget`；Busy 有效切换节点也参与 pinned indices，必要时自动提升 `effective_max_points`，超过安全上限时按既有策略抽样并返回 warning。
7. 空口负载显示偏好通过既有受控 UI preference 通道保存：
   - `mesh-analysis-airload.show-switch-lines`
   - `mesh-analysis-airload.show-switch-points`
8. RSSI 图的既有 `mesh-analysis-rssi.*` 偏好和节点对齐逻辑没有被复用污染。
9. 切换开关、Peer Busy 和站点/区间显示属于 presentation 更新，不会主动重新查询，也不会重置当前 `dataZoom`。
