# R5.0.4 Chart Interaction Test Report

## Automated interaction coverage

The renderer tests cover the synchronization contract without claiming native GUI acceptance:

1. Quick Ping options pin `xAxis.min/max` to the full playback run and expose absolute viewport `startValue/endValue`.
2. Quick Ping enables wheel and pointer movement on its inside dataZoom and converts percentage payloads back to absolute timestamps.
3. Parent viewport changes are propagated to every mounted chart stub with identical `visibleStart/visibleEnd` values.
4. Cursor events update only `selectedTime`; they do not recenter the viewport.
5. Event-row actions continue to use the recentering path.
