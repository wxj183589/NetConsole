## 源码结构审查

- `MeshPhase11Workbench.vue` 的 `.phase11-nav` 是七项业务入口的同一容器，flex + 横向 overflow，white-space:nowrap，button 不收缩；导航项不因宽度不足换成第二行。
- 主页面通过 `workspaceChange` 与 slot 继续使用原链路/RSSI/切换/报告业务内容；没有为导航切换重新创建整个 MESH 页面。
- 不再提供独立「日志解析」业务导航；解析状态和异常在概览 details 内，保留查询能力。
- 六张概览卡片限定 overview；AP 和主监控不重复显示。
- 主监控工作区切出时取消旧请求、清除当前图表数据；返回用条件缓存恢复并后台刷新。筛选与共享窗口状态不因普通导航切换重置。
- scope 是业务范围；切换触发相应业务刷新。解析异常与 scope 无关，使用独立缓存/控制器，避免无意义重查。Session 变化清理旧结果。
