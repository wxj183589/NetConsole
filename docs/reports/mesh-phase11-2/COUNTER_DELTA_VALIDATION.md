# 计数器增量验证

## 契约

增量=当前累计−前次累计；每秒速率=增量÷真实采样间隔。身份含source、Radio、Peer、建链时间及双方AP/射频身份，避免跨身份相减。角色切换、ACTIVE通道切换、重置、零链路和长间隔断开基线；重复/倒序点不污染后续有效基线。未登记位宽，下降按重置/无法确认的回绕处理，不猜测溢出位数。

首点、缺失和无有效间隔的速率为null；合法零增量为0。各身份独立维护采样节奏。降采样按每秒速率保留极值及边界。DTO保留旧delta并新增counter_samples，前端默认展示每秒速率，不回退delta。
