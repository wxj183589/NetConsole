# Mesh Phase 11 实施计划

## 范围

- 在 MR 原始 MESH 日志分析中提供分析概览、日志解析、AP 情况、主链路监控四个业务工作区。
- 主链路监控复用已有业务接口，按 ACTIVE/备链路组织数据，并提供 RSSI、CPU、内存、Tx/Rx Busy、Rate、Noise、TxDesFreeCnt、Counter 八组趋势。
- 请求按工作区和图表独立加载，使用 AbortController、请求代数和短期缓存保护快速切换。
- 普通业务列只保留 AP、站点、区间、链路状态、信号、负载和流量相关字段。

## 完成标准

1. 页面骨架和业务导航可见，首次数据返回后逐块填充。
2. 图表状态经过查询、处理、绘制并收到 ECharts `finished` 事件后才标记完成。
3. 单个图表失败不阻塞其他图表；缓存命中不重复显示长加载遮罩。
4. 真实开发数据下完成 Electron 1920×1080 主流程截图。
5. Renderer 类型检查、构建和定向测试通过。
