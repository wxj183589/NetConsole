# Mesh Phase 11 UI 设计交付

## 工作区

顶部只保留四个业务工作区：分析概览、日志解析、AP 情况、主链路监控。旧建链顺序、链路明细和 RSSI 功能继续位于下方兼容区域，避免破坏既有分析动作。

## 主链路监控

- 左侧显示 ACTIVE、STANDBY、Counter 样本和风险 AP 摘要。
- 中间以八个独立指标面板绘制时间趋势：RSSI、CPU、内存、TxBusy/RxBusy、Rate、Noise、TxDesFreeCnt、Tx/Rx/Retry/Err/GARP/MulJoin。
- 右侧显示用户选中的采样记录详情。
- 底部显示主链路记录，点击记录更新详情。
- 图表面板固定高度，加载状态只占用面板内部空间，不遮挡已完成的其他指标。

## 业务字段

AP 表只展示 AP 名称、AP MAC、站点、区间、信号和采样信息。解析异常表只展示级别、异常类型和简要说明。内部追溯信息继续留在 API 和诊断导出中。
