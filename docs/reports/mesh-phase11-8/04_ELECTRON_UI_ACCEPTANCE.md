# Electron 界面验收

Windows 11 10.0.26200，Electron 43.1.1，实际源码工作树 `d2740ddf-dirty`。独立 Electron 窗口和 Python 后端启动，界面显示宁波地铁12号线、目标会话及主链路监控。启动时 Vite 依赖重新优化导致一次动态模块加载失败，之后界面恢复并发起查询；原因和复现条件待核实。

`screenshots/01-main-monitor.png` 为 Windows PrintWindow 获取的真实 Electron 窗口，1280×800；屏幕为 2560×1440，未修改系统显示配置。截图显示 RSSI、CPU 图表及 AP 详情，并显示部分图表的“切换事件过密，请缩小时间范围”提示。该提示对应后端采样边界保护；缩小范围后的体验尚未验收。截图不是任务指定的 1920×1080 验收。完整操作序列、滚轮、Tooltip、状态恢复与其余截图均未完成。
