# Phase 11.9 后续实施记录

日期：2026-11-10。基线：`8ba955f2`。状态：`PHASE_11_9=PARTIAL`。

## 本轮实现

- 主链路历史与建链分页增加有界缓存，支持同一条件下已访问页复用。
- 仅当第一页返回总数等于记录数且未降采样时，才从包含区间筛选子窗口；历史按采样时间筛选，建链按建链区间相交筛选，零链路按观测时间筛选。时间边界均包含端点。
- 缓存键包含会话、页大小和现有全部非时间筛选条件；缓存最多 32 页，按最近使用淘汰。明确刷新、会话切换和组件卸载时清理。取消或过期响应不写入缓存。
- 保留既有指标缓存、请求取消和图表交互。没有将计数器跨窗口直接拼接：前序采样和增量受窗口边界影响，尚需与后端结果逐条核对。
