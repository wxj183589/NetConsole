# Phase 11.7 性能报告

结论：`PERFORMANCE_STATUS=PARTIAL`。

## 当前环境事实

- 只读目录核对：宁波地铁12号线 MESH 根有 186 个文件，合计约 1,097,077,578 bytes（含数据库/WAL/SHM及原始文件；不是解析记录数）。目标列车01-MR-CW parsed SQLite 文件 156,786,688 bytes。
- 目标 parsed DB/raw 的本轮记录数、加载分阶段耗时、首图绘制时间、页面完整可交互时间和峰值内存均未采集。
- 不以文件字节大小替代日志行数或记录总量。

## 可引用的历史真实只读 Service 基线

Phase 11.2 `real-service-query-validation.json` 使用当前当时源码 Service 直接只读宁波数据，记录：三秒窄窗口 4 条记录、查询 2.50 ms；默认末尾五分钟窗口 465 条原始记录，降采样返回 240 条，单次耗时约 2190.47 ms / 2306.04 ms。该结果不包含本轮运行态 API、当前完整 Electron 页面/首绘、也不构成稳定 SLA，故只作为历史背景。
