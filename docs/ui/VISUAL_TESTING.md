# UI 视觉测试

公共表格单元测试必须覆盖表头长于内容、内容长于表头、空数据、中英文、排序/筛选图标、状态 Tag、操作按钮、最大宽度、横向滚动、手工列宽和恢复自动宽度，并断言 `computedWidth >= headerRequiredWidth`。

阶段 7 使用固定 fixture、字体、窗口、语言和主题建立 Playwright 截图及 DOM 断言，覆盖设备管理、设备详情、FIT-AP、Online MR、任务中心、Traffic、Agent 和系统设置。像素截图不能替代以下 DOM 事实：

- 表头未被裁剪或异常换行；
- 内容和表头按列定义对齐；
- 长内容具有 Tooltip；
- 横向滚动区域可用；
- 操作按钮完整且可聚焦；
- 页面卸载后无监听器或测量任务残留。

矩阵包含中/英文、浅/深主题、三个标准窗口和 100%/125%/150% 缩放。当前仅建立测试契约，核心页面截图基线尚未生成，状态为 `PENDING`。
