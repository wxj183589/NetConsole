# 响应式布局

Electron 页面根区域保持 `min-width: 0` 和流式宽度，页面本身不因宽表产生横向滚动。标准表格由 `.nc-data-table__scroll` 承担横向和必要的纵向滚动；避免页面、卡片、表格、单元格四层滚动。

空间不足时顺序固定为：保持字段最小宽度、保持表头完整、启用表格横向滚动。最大化和 2K/4K 工作区由共享 Shell 完整利用；1280×720 下动作区仍需可达。弹窗和抽屉内容超出时提供内部滚动，不能挤压按钮或把表头压成多行。

阶段 7 需要覆盖 1280×720、1920×1080、2560×1440 与 100%、125%、150% 缩放；完成前状态为 `PENDING`。
