# Windows Server 便携版测试清单

## 解压与启动

1. 解压目录不要放到中文特殊权限目录，建议使用 `C:\NetConsolePortable`。
2. 直接运行 `NetConsole.exe`。
3. 检查 demo 站点是否自动创建。

## 页面检查

1. 检查设备管理页面是否正常打开。
2. 检查 AC管理页面是否正常打开。
3. 检查运行日志页面是否正常打开。

## 连接与采集

1. 检查测试连接 `10.0.0.51`、`10.0.0.52`、`10.0.0.53`。
2. 检查设备详情更新是否正常。
3. 检查 AC管理更新是否正常。

## 日志与数据

1. 检查 `data/logs/app.log` 是否生成日志。
2. 检查 `data/sites/demo/raw/collect` 是否生成采集日志。
3. 检查 `data/sites/demo/raw/ac` 是否生成 AC 采集日志。

## 系统环境

1. 检查杀毒软件是否拦截 `NetConsole.exe` 或采集连接。
2. 检查防火墙是否允许访问 `10.0.0.51`、`10.0.0.52`、`10.0.0.53`。
3. 检查是否缺少 VC runtime 或 DLL。
