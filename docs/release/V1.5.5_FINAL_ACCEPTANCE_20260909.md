## 本轮收口内容

### 轨旁 AP 与 AC 未认证状态

- 轨旁 AP 业务页改为紧凑 KPI Strip，诊断默认单行收起，低频操作进入“更多”，并增加面向 1080 高度的 compact mode。
- 查询区与业务表格采用独立可用空间和滚动布局，保留 FIT-AP / LLDP 时效展示。
- `display wlan ap unauthenticated` 改为当前快照语义：成功有记录保存当前集合；成功空串或仅 H3C prompt 记为 `SUCCESS_EMPTY` 并清空当前集合；失败、超时或非空不可解析记为 `UNKNOWN`，不复用历史缓存。
- AC 管理显示“未认证 AP（AC实时）”，历史 `is_new_online_ap` 等事实不再推断当前未认证状态。

### SSH Relay

- Jump Host 使用独立 `AUTO_REPLACE` 主机指纹策略：首次自动登记，变化后仅原子替换当前 `host:port` 并记录旧/新 SHA256 指纹，不要求人工确认。
- SSH Relay 启用且配置完整后保存即启动；Backend 启动和局点切换自动恢复。
- 局点 A→B 切换先关闭并移除旧 Jump Manager，再启动新局点 Relay。
- Relay 启用但不可用时，内部 SSH consumer 不静默回退 Direct；Ping/ICMP、SNMP、UDP 不受 Relay 影响。
- Target Device、SFTP 和既有严格 Host Key consumer 未被全局改成 AUTO_REPLACE。

### Task Center 动态通知 P1

现场发现多设备批量任务完成后，warning/failure 的 Element Plus 动态通知 `duration=0` 会长期占据右上角。

修复后：

- success：5 秒自动关闭；
- warning：8 秒自动关闭；
- failure：10 秒自动关闭；
- 同时最多显示 3 条任务通知；
- 保留 800ms 批量终态聚合，避免多设备任务逐条刷屏；
- 增加终态去重，并允许正常终态后最多一次告警升级；
- 动态通知自动关闭不影响 Task Center 中失败/告警任务、徽标、确认状态和历史记录。
